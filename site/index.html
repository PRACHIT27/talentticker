What this is. The skills ticker can only count things it already knows about. This list works the other way round: it reads every posting, finds named technologies that were barely mentioned a few months ago, and ranks them by how fast they climbed. It is how you spot a skill before it is on anyone's list.

"Companies" matters most. A term used by one employer across many postings is house style; a term showing up at six different companies is a trend.
